# Rick and Morty

A native iOS application that displays and explores characters from the *Rick and Morty* series using data retrieved from a public API.

The application was built as a practical exercise in implementing a structured, responsive, and functional iOS application while following common native development patterns.

## Features

* **Character Browser** — Displays characters from the *Rick and Morty* universe in an interactive list.
* **Search** — Allows users to quickly find characters by name.
* **Character Details** — Displays information such as status, species, origin, location, and other character statistics.
* **Episode Information** — Provides access to episodes associated with characters.
* **Interactive UI** — Uses dynamic table/list components to provide a smooth browsing experience.
* **API Integration** — Retrieves and processes data from the Rick and Morty public API.

## Purpose

The project focuses on demonstrating core iOS development skills, including API integration, asynchronous data handling, dynamic UI development, navigation, state management, and the implementation of a clean and functional native application.
